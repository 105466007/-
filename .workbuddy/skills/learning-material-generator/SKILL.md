# 学习资料生成器（Learning Material Generator）

把任意一个概念变成一份"能学、能练、能检验"的单页学习资料。
本 Skill 的目标不是"讲一遍"，而是产出一份**结构固定、质量可检验、可长期沉淀**的个人学习资产。

## 适用场景

- 学习一个新的技术概念 / 框架 / 方法论，想要系统性的入门资料
- 学过但感觉没吃透，需要一份带自测的复习材料
- 团队/个人知识库需要统一格式的概念讲解页
- 为后续学习者沉淀"一份就够"的概念入门文档

**不适用**：需要实时数据的查询（如"今天 XX 股价"）、操作类任务（如"帮我装环境"）。

## 输入

| 输入项 | 是否必填 | 说明 |
|--------|----------|------|
| 概念名称 | 必填 | 例如：Agent、大模型的上下文、Skill |
| 学习者水平 | 可选 | 入门（默认）/ 进阶 / 专家，决定讲解深度和类比选择 |
| 学习者已有的疑问 | 可选 | 生成时优先解答 |
| 个人理解初稿 | 可选 | 学习者自己的话，会被保留并标注在"个人理解"区 |

## 生成步骤

1. **明确边界**：确认概念的中英文名称、易混淆的近义概念（如 Agent vs Chatbot）。
2. **定学习目标**：写 3–5 条**可检验**的目标（用"能说出 / 能区分 / 能举例"开头，不用"了解 / 掌握"）。
3. **核心概念**：一句话定义（忠实官方口径）+ 一个生活化类比 + 3–5 个关键词卡片。
4. **机制原理**：拆成 3–6 个步骤或组件讲"它怎么运作"，配纯 CSS/SVG 的示意图（不依赖外网图片）。
5. **应用场景**：选 1 个具体、真实、有代入感的场景，走一遍完整流程。
6. **常见误区**：2–3 组"X ≠ Y"式辨析，每组给出错误认知、为什么错、正确的理解。
7. **自测题**：3–5 道，必须覆盖全部学习目标；每题附答案与"答错说明什么"。
8. **参考资料**：官方文档优先，链接必须真实；每条附一句"什么时候读它"。
9. **个人理解区**：若学习者提供了初稿则润色保留；否则留出带日期的留白模板，**不得代写**。

## 输出结构

输出单文件 `learning-materials/<概念slug>.html`，自包含（内联 CSS/JS，无外链资源依赖），
固定章节与导航：

```
学习目标 → 核心概念 → 机制原理 → 应用场景 → 常见误区 → 自测题 → 参考资料 → 个人理解
```

页面风格：浅色主题、清晰层级、适合打印与长阅读。

## 写作约束

- 使用简体中文，术语首次出现标注英文原文
- 定义必须与官方文档一致；推测内容必须标注"⚠️ 个人推测"
- 不编造参考文献、链接、引用；找不到可靠来源就写"暂未找到权威来源"
- 误区部分必须给出"为什么错"，不能只罗列错误说法
- 自测题不许出"送分题"，要能真的暴露理解偏差

## 质检清单（生成后逐项自检）

- [ ] 学习目标全部可检验，且被自测题完整覆盖
- [ ] 核心定义与官方文档口径一致
- [ ] 机制原理的每一步都解释了"为什么需要这一步"
- [ ] 每组误区都有辨析而不是罗列
- [ ] 自测题答案正确，且能区分"真懂"和"背下来了"
- [ ] 参考链接真实存在且与主题相关
- [ ] 个人理解区已保留（润色初稿或留白），未由 AI 代写观点
- [ ] 页面离线可打开，无外链资源

## 维护说明

- 若概念发生重大变化（如规范更新），重新运行本 Skill 并核对变更点
